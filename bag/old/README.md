# `bag/old/` —— 被后一次录制**取代**的旧包（2026-10-08 操作者拍定）

规矩一句话：**每个场景只在 `bag/` 一层留最新最有用的那一份**，其余搬到这里。
搬是**搬、不是删** —— 这些包仍然入库、仍然能回查，只是**不再进总表**
（[`bag/MANIFEST.md`](../MANIFEST.md)）与收编（`run/z0.py rec_adopt`）。

★ 这两件事是**按目录名 `old` 认的**，写在 `run/rec.py` 的 `ARCHIVE_DIRNAME`
（收编时跳过它**不算"认不出场景"**，所以不会把它报红；总表本来就只扫 `bag/` 一层，
天然看不到这里）。**别把这里当成"随便扔认不出的东西"的地方** —— 目录名认不出场景时
`rec_adopt` 的纪律是**报红、不动它**，那条纪律留着。

## 搬进来之后的三份要小心读的地方

- **`4_traj3_lemniscate/` 是老编号**：09-29 那天"4"是八字，"5"还不存在。它的
  `session.json` 里 `scenario: 4`、`slug: 4_traj3_lemniscate` 是**当时的事实**，不抹平；
  `run/rec.py` 的 `SLUG_ALIASES` 会把"认目录名"这一步认回**当前的场景 5**。
  §这层别名现在只在**别处**（例如 `tools/px4-sitl/` 那套夹具）还按老路径引用它时才有意义 ——
  `bag/` 一层里已经没有这个目录名了。
- **`5_traj3_lemniscate/`（空的那份）** 不是"某次录坏了"就完了：**那一趟飞机是飞成功的**
  （第一手：配它的飞控日志 `log_2_未知日期.ulg` 解锁区间 34.5 s，与链侧那趟的 34.9 s 差 0.4 s）。
  见 [`5_traj3_lemniscate/fcu/INDEX.md`](5_traj3_lemniscate/fcu/INDEX.md)。
- **`3_traj1_hover/` 与 `4_traj3_lemniscate/` 是别人在用的夹具输入**：`tools/px4-sitl/` 下
  那套（`mocap_model.py` / `verify_tier_b_seam3.py`）以及它们冻结的证据
  （`tools/px4-sitl/evidence/tier-b/mocap-model-{3,4}.json` 里那句 `"bag": "bag/3_traj1_hover"` /
  `"bag": "bag/4_traj3_lemniscate"`）**都是照这两个路径记的**。
  ⟹ 那份证据记的是"当时用的是哪一份数据"，那些**路径在写下的那一刻是对的**；
  但**今天**拿它们去跑，路径得换成 `bag/old/3_traj1_hover` / `bag/old/4_traj3_lemniscate`
  —— 否则 `bag/3_traj1_hover` 现在装的是 **10-08 另一次飞行的数据**，重新生成的夹具会
  与冻结的那份对不上，而**症状是"数变了"、不是"路径错了"**，很容易被误读成模型的问题。
  这条是这次搬家**唯一**会咬人的地方。
