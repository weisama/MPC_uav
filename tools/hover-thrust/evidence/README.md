# `hover_thrust` 反推的原始证据

**为什么有这个目录**：ticket [phase2/10](../../../.scratch/phase2/issues/10-param-measure-backfill.md)
的交付物是一个**有出处**的 `hover_thrust` —— 本张票的 P1 输入就是它。
而本目录里的验证日志**不在 git 里**（SITL 的 175 份 ulog，约 1 GB，在
`~/refs/px4-v1.14.3-build/build/px4_sitl_default/rootfs/log/`）。
所以关键几件**放进 git**，让出处链不依赖任何一台机器的临时目录。

⚠️ **本目录证明的是"工具的读数对不对"，不是"z0 的 `hover_thrust` 是多少"。**
真机那个数必须来自 z0 自己的 P1 悬停日志 —— 见下面第 4 条。

## 文件

| 文件 | 是什么 | 它支持什么 |
|---|---|---|
| `sitl_log_10_42_47_2026-09-28.json` | 单份 SITL 日志的**工具完整输出**（判据、候选段、读数、HTE、sha256 都在里面） | 一次端到端验证的全过程；`sha256` 给出可回查的输入指纹 |
| `sitl_log_10_42_47_2026-09-28.txt` | 同一份的**人读版**（工具的标准输出原样） | 上面那份 JSON 的可读对照 |
| `sitl_corpus_175_logs_2026-09-28.txt` | 175 份 SITL 日志的**批跑原始输出**，含 4 档速度门的敏感性表 | 跨日志复现性 + 「读数不随判据移动」 |

两份都由**仓库里的这版代码**产出，命令见文末。

## 1. 真值对是怎么来的（SITL 同构机）

SITL 的被控对象是 z0 的同构机（[`tools/px4-sitl/z0-plant/plant_spec.py`](../../px4-sitl/z0-plant/plant_spec.py)），
它的悬停推力是**解析算得出来**的（`plant_spec.py:42-46`）：

```
T_hover   = m·g            = 0.750 kg × 9.80665 = 7.3549875 N
T_max_tot = 4 × SIH_T_MAX  = 4 × 2.95 N         = 11.8 N
hover_thrust ≡ T_hover / T_max_tot = 0.623304025…
```

**实测读数**（`sitl_log_10_42_47_2026-09-28.json`）：

| | 值 |
|---|---|
| 工具读数 | `0.623304009437561` |
| 解析真值 | `0.6233040254237288` |
| **相对偏差** | **2.6 × 10⁻⁸** |

差这么点只剩一个解释：`thrust_body` 在 msg 里是 **`float32`**，传到日志已经量化过一次。
也就是说 —— 在"日志足够干净"这个理想条件下，工具**没错**：符号约定、段选取、稳态论证、
`|thrust_body[2]|` = `hover_thrust` 这条等式，全都对上了。

| 结局 | 份数 |

| ✅ 可用读数 | **50** |
| ⚠️ 有飞行、但无稳态段 / 段间不一致 | 22 |
| · 没有飞行段（SITL 没起来 / 没起飞） | 88 |
| 缺必需 topic（工具**干净退出**，非崩溃） | 15 |
| **崩溃** | **0** |

50 份**独立**日志的读数：范围 `0.62330 – 0.62330`，**极差 0.0000%**。
（另有 2 份给出试读值但被判段间不一致 —— 它们各自含一段 0.46–0.48 的推力，见第 3 条。）

> **复核轮重跑（2026-09-28，同上命令）**：代码在复核中改过（`_in_flight_mask` 改走 `_load(..., optional=True)`，

> 崩溃 `0`、去重读数仍只有 `0.62330` 一个。单份那份的输出与入库 JSON 只差一个 `analysed_at` 时间戳。

## 3. ★ 读数不是被判据挑出来的（这条比上面两条都重要）

"50 份都得到同一个数"本身**不能**排除一件事：这个数是**判据筛出来的** ——
换一档速度门就换一个数，只是恰好挑到一个"好看"的档位。
所以批跑里扫了 4 档（0.15 / 0.30 / 0.40 / 0.60 m/s），结果：

```
所有档位、所有日志出现过的读数（去重）：0.62330   160 次
逐对比较：共同日志里读数不同的份数一律为 0
```

**4 档 × 175 份，只出现过一 个读数。** 判据改变的只是**有多少候选段被判掉**：

| `v_eps` | 可用读数 | 判据松掉之后多出来的候选段长什么样 |
|---|---|---|
| 0.15 | 3 | ——「没有一段够 2 s」，等于**什么都测不出来** |
| **0.30（默认）** | **50** | —— |
| 0.40 | 48 | 多进来的段带 0.47–0.51 的推力，段间不一致 19–24% ⟹ 被判掉 |
| 0.60 | 49 | 同上，另有一份段内不一致 29% 被判掉 |

**两端都不是好选择**：0.15 太紧（真机悬停本来就有厘米级漂移，SITL 的"悬停"更是慢漂轨迹，
在飞窗口中位速度 0.17 m/s），0.60 太松（放进来的是**瞬态**，靠一致性判据补救）。
0.30 是"慢漂留下、机动挡掉"的那一档。误差界不靠这个数，靠
`tilt_eps = 10°`（⟹ 1.5%）与 `δ ≤ 2·v_eps/(g·T)`（⟹ 3.1%），见
[`hover_thrust_core.py`](../hover_thrust_core.py) 里 `steady_hover_mask` 与 `sustained_error_bound` 的说明。

## 4. 这份证据**不能**替代什么（诚实交代）

1. ★★ **它不能给出 z0 的 `hover_thrust`。** 上面那个真值 `T_max_tot = 11.8 N`
   来自 [`phase2-implementation.md`](../../../docs/control/phase2-implementation.md) **§3.3 的占位值**
   （`plant_spec.py:43` 自己注明了这个出处）。所以整个验证是**自洽性**检查：
   "工具能不能把被控对象自己的悬停油门读回来"，**不是**独立测出了 z0 的电机/电池能力。
   真值必须来自 z0 自己的 P1 日志（ticket 10 的待填字段）。
2. **不含 ulog 本身。** 1 GB 的 SITL 日志不进 git。能回查的是
   「那一次跑的是什么样的数据、用什么方法、得到什么数」——要真正复跑，
   得先有同样的 175 份日志，并核对 `sha256 = 87f4a2c960432e9b7b9e9bf30d52e725daedf4d33e15cc9e316bd67db2681f2a`（单个日志那份）。
3. **只用 SITL 验证过，真机日志一次都没跑过。** SITL 没有气动阻力、没有电池掉压、
   没有振动 → 真机上"稳态"会比这里难判得多。**工具在真机上尚未验证。**
4. **`hover_thrust_estimate`（飞控自己的估计）不是独立口径。** `MPC_USE_HTE = 1` 时位置控制器
   用的就是它，两者一致是同义反复。SITL 上实测它是 `0.5` 且 `valid = 0`（没收敛）——
   同一份日志的主口径给出 0.6233。**拿它当读数会得到错的数**，工具把它单独打印并标注了这个警告。
5. **不修正竖直加速度。** 本工具只用速度与倾角做判据，
   `vehicle_local_position` 里的 `ax/ay/az` **不读**（自检里有用例钉住这点）。
   想"用加速度把推力修正回去"要另开一张票，那会**改变读数口径**。

## 怎么复跑

```bash
# 单份（端到端，带独立真值对）
python3 tools/hover-thrust/hover_thrust_from_ulog.py \
    ~/refs/px4-v1.14.3-build/build/px4_sitl_default/rootfs/log/2026-09-28/10_42_47.ulg \
    --expect 0.62330 --model-hover 0.6235 \
    --json tools/hover-thrust/evidence/sitl_log_10_42_47_2026-09-28.json

# 一批（跨日志复现 + 判据敏感性）
python3 tools/hover-thrust/corpus_check.py \
    ~/refs/px4-v1.14.3-build/build/px4_sitl_default/rootfs/log \
    --expect 0.62330 --v-eps 0.15 0.30 0.40 0.60

# 不需要任何日志的那部分（36 条）
python3 tools/hover-thrust/test_hover_thrust_core.py --self-test
python3 tools/hover-thrust/test_hover_thrust_from_ulog.py --self-test
```
