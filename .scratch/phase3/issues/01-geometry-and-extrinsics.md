# 01: 装桨前台架几何测量 —— 电机实际位置 + 动捕刚体↔IMU 外参

Status: ready-for-human
Type: task

**What to build:** 两个只能拿卡尺在飞机上手量、且**必须在装桨之前量完**的几何量：四个电机的实际位置，和动捕刚体原点相对 IMU 中心的偏移。

两半都是「测量 + 一个判定」，**都不是「改一个数」** —— 各自的判定逻辑不同，"没做对"长什么样也不一样，见下面两组判据。

**Blocked by:** 无（本 feature 内可立即开工）。但**外参那一半**依赖动捕链路已通 —— 跨 feature 依赖 [`.scratch/phase1/issues/04-mocap-relative-pose.md`](../../phase1/issues/04-mocap-relative-pose.md)；几何那一半不受它阻塞。

## 几何（P1 / `params-changes.md` A2–A3）

⚠️ **关键不是「改」，是「先判断」。** `CA_ROTOR0..3_PX/PY` 的现值是 PX4 Generic Quad X 的默认半展，比 z0 实际几何**大 2.79×** —— 但多旋翼分配器按几何**自身范数**归一化，**均匀缩放会被完全约掉**。所以"改了会不会有效果"取决于实测结果，不取决于几何是否写错。

- [ ] 四个电机的实际位置实测（机体系 x 前 / y 右 / z 下），并算出实际轴距
- [ ] **先判断是否只是均匀缩放**（`PX == PY` 整体等比），而不是先改数
- [ ] 若是均匀缩放 → **不动** `CA_ROTOR*_PX/PY`，并把「为什么不改」写进文档（否则后来者会以为这是遗漏）
- [ ] **若不是**均匀缩放（`PX ≠ PY` 或非正 X 布局）→ 改几何 **并同时重调** `MC_ROLLRATE_*` / `MC_PITCHRATE_*` / `MC_YAWRATE_*`；★ 重调后角速率环**必须重新验证**，不能只改一半留下一个配错的角速率环
- [ ] 实测值与判定写进文档，并从本文件回链

## 外参（P3 / `params-changes.md` C2）

`EKF2_EV_POS_X/Y/Z` 现值 `0/0/0`。**若动捕刚体原点刻意定义在 IMU 上，`0` 就是对的** —— 本票要区分「对」和「没做」。

- [ ] 量出动捕刚体原点 → IMU 中心的偏移（机体系 x 前 / y 右 / z 下，m）
- [ ] 回填 `EKF2_EV_POS_X/Y/Z`；**或**显式确认「刚体原点刻意定义在 IMU 上 → `0` 是正确的」，并把这个理由写进文档
- [ ] 判据：位置估计里**没有常值偏移**（不是"看起来还行"）
- [ ] 结论写入文档并从本文件回链

---

**为什么是 `ready-for-human`**：卡尺、飞机在手上、以及「这个偏差算不算均匀缩放」这种判断，AFK agent 做不了。

*⚠️ spec 层约束：Phase 3 不与 Phase 1 / Phase 2 并行开工。本票虽是纯测量，仍排在 Phase 2 达标之后。*
