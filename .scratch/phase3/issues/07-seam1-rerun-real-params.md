# 07: Phase 2 的 seam 1 用实机参数重跑

Status: ready-for-agent
Type: task

**What to build:** MPC（模型预测控制）节点的 ROS 话题边界测试**用实机参数重跑一次** —— 喂脚本化的输入话题，断言发出的话题，peer 用假件。

**Blocked by:** [05](05-first-flight-config-freeze.md)（要用冻结后的参数，而不是仿真参数）。

**它挡的是什么**：**不是**控制律正确性 —— 那已在 Phase 2 的 SITL 里验过，重测等于重复劳动。它挡的是**「搬到真机后参数 / 话题改错了」这一类错误**：话题名、QoS、时间戳单位、频率、τ、悬停油门、推力归一化常数、`body_rate` 掩码。成本≈0，漏掉的代价是天上才发现。

- [ ] 用**实机参数**（频率 / τ / 悬停油门 / 推力归一化常数）重跑，而不是仿真参数
- [ ] 断言范围与 Phase 2 的 seam 1 一致：符号映射表、推力归一化、NaN 整帧丢弃、求解失败兜底、心跳频率、QoS 可通、时间戳单位、未解锁 / 未在 OFFBOARD 时不发布
- [ ] **不新增 seam** —— 本阶段刻意不新增任何 seam 形态，这一张只是 Phase 2 seam 1 的**第三次应用**
- [ ] 若断言失败：**归因**到「参数搬错 / 话题改错 / 夹具过时」三者之一并记录，**不就地放宽断言**
- [ ] 跑法与结论记入文档，使未来换机时能照做

---

**为什么是 `ready-for-agent`**：纯软件、台架上跑、不需要飞机通电。

**✅ 本票是 Phase 3 里少数完全 AFK 可推进的一张。**
