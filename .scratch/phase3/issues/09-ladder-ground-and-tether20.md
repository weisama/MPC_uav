# 09: 阶梯 1+2 —— 拆桨看方向 → 系绳 + 离地 20 cm 只给悬停推力

Status: ready-for-human
Type: task

**What to build:** 飞机第一次被 (C) 级指令驱动的**两次**验证：一次完全离地之前，一次极低空。

⚠️ **这两级是整条阶梯里最便宜、也最不可跳过的一级**。符号错误在天上表现为「**直接朝错的方向加速**」，在这里表现为「某个电机转速差方向不对」—— 前者摔机，后者只是我多拧一次桨。

**Blocked by:** [06](06-ladder-acceptance-criteria.md)（判据必须在**转桨之前**定稿）、[07](07-seam1-rerun-real-params.md)、[08](08-safety-paths-and-fallback-drill.md)，以及跨 feature 的 [`phase2/issues/11-sitl-tier-b-seam3.md`](../../phase2/issues/11-sitl-tier-b-seam3.md)（SITL 达标 —— 阶梯是它之后的关卡）。

## 阶梯 1 —— 拆桨

- [ ] **桨叶全部拆掉**，只做地面验证 —— 这样符号错误不会造成伤害
- [ ] 只给 **±小角速率**指令，**目视电机转速差方向**与预期是否一致
- [ ] ★ **方向错就停，不进下一级** —— 归因到符号映射表并修正后，**本级的判据从头重新跑一遍**（不是"改完继续往下走"）
- [ ] 本级同时把 `thrust_body` 的**符号与范围**认知落到实物上：它是 `[-1, 1]`，**不是** `[0,1]`、**不是**牛顿 —— 符号写反会全速砸地

## 阶梯 2 —— 系绳 + 离地 20 cm

- [ ] 系绳，**只离地 20 cm**，**只给悬停推力**，不给任何轨迹 —— 即使控制发散也不造成损坏
- [ ] 判据：推力**方向正确**、无异常振荡、能稳定悬停在该高度附近
- [ ] 若缓慢上飘 / 下坠 → 归因到**悬停油门标定**（[02](02-hover-thrust-backfill.md)），**而不是就地调增益**
- [ ] 本级的阈值用 [06](06-ladder-acceptance-criteria.md) 定稿的量化值，**不事后调**

## 两级共同

- [ ] 每一级**停下来看日志**，**不通过不进下一级**
- [ ] 日志完整记录 MPC（模型预测控制）内部状态、求解耗时、约束饱和标志、**实际指令与实际状态** —— 使飞行后能复盘而不只依赖记忆
- [ ] 各级的结论写成「条件 + 数值」的可复核记录；过不了就写成「**未达标 + 实际数值**」，**不写"基本通过"**

**为什么是 `ready-for-human`**：拆桨、系绳、目视判方向，全是手上的活。
