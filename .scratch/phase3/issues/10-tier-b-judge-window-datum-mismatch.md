#### 一、修法：**让判层自己换算**（票面 ★ 建议的那条），不是票面列的两条路

新增一支纯函数，把"记录器钟 → 绝对墙钟"的零点**从 obs 自己身上推出来**：

```python
def rec_clock_zero(frames, tt):        # → rec.t0（秒）；取不到返回 None
    fs = [f for f in (frames or []) if f.get("wall_ns")]
    ff = (tt or {}).get("first_frame")
    if not fs or not isinstance(ff, (int, float)):
        return None
    return fs[0]["wall_ns"] / 1e9 - float(ff)      # 同一刻的两根钟，相减就是零点
```

`_flight_window()` 的主分支再用它把 `offboard_enter_t` / `flight_end_t` 抬到绝对墙钟上，
与 `frames[].wall_ns` / 真值第 7 列**同一根钟**。退路分支本来就是绝对墙钟，不动。

**为什么不选票面那两条（"要么把 `rec.t0` 写进 obs，要么在采集侧就换算好再落盘"）**：

| 路 | 为什么没选 |
|---|---|
| (a) 把 `rec.t0` 写进 obs | 它是给**采集侧**（`verify_tier_b_seam3.py:652/:661` 那一带写 obs 的地方）加键 ⟹ **救不了已经落盘的六份归档**，而验收第 3 条要求的正是"**重判归档 obs**、修前红修后绿"；归档不就地改，所以这条路的产物是**下一批**才有的 |
| (b) 采集侧就把这两个键换算成绝对墙钟 | 同上，救不了已落盘的批次；且它让**同一个键名在新旧 obs 里是两个意思**（旧的是记录器钟、新的是绝对钟）—— 把"零点含糊"从"判的时候混用"搬成"落盘的时候就含糊"，是把病挪个地方；`obs["t"]` 里 `offboard_enter`（相对 `t_before`）与 `offboard_enter_t`（记录器钟）现有这层区分也会被搅浑 |
