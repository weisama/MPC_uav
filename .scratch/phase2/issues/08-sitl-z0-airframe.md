# 08: z0 同构 SITL 被控对象（含参数失配开关）

Status: ready-for-agent
Type: task

**What to build:** 一个**动力学与 z0 同构**的 SITL 被控对象。

`gz_x500` 的动力学与 z0 差得远，**"在 x500 上能飞"证明不了"在 z0 上能飞"**。所以 SITL 要重新生成一份符合 z0 的模型，而不是拿现成机型凑。

**Blocked by:** [01](01-sitl-px4-msgs-baseline.md)

- [ ] 在**上游 v1.14.3（tag `1dacb4c`）**构建出的 SITL 上新增一份 z0 同构机型（构型、推力方向、机体几何按 z0）—— ☠️ 原写"在 fork `5ba2e91f` 构建出的 SITL 上"，**该 fork 与 z0 无关**
- [ ] 质量 / 推力系数 / 转动惯量 / 内环时间常数等参数按 z0 取值，且**单参数 ±30% 失配可切换**（供 [12](12-mismatch-sweep.md) 用 —— 开关是刻意留的，不是顺手加的）
- [ ] 另留**一套参数一致的对照组变体**
- [ ] SITL 侧的 PX4 参数与 z0 一致，含 `MPC_TILTMAX_AIR` 收到 **30°**
      ⚠️ 注意这是 **PX4 的位置控制器参数**（Multicopter Position Controller），与模型预测控制**毫无关系** —— 收它的理由是电池限制下的推力裕度，不是 MPC（模型预测控制）的需要
- [ ] 参数变更记入 [`params-changes.md`](../../../docs/reference/params-changes.md)
- [ ] 机型与参数写入文档，使 12 的扫描**可复现**（参数值、切换方式、如何复原）
- [ ] `gz_x500` 在文档里被明确标注为**仅最早期冒烟目标**，**不得用于 SITL 验收**

---

**为什么失配是交付物而不是副作用**：若这个 MPC（模型预测控制）只在参数精确匹配时不发散，那它在 z0 上就**没有裕度**。**"错参数也能飞稳"本身是 [11](11-sitl-tier-b-seam3.md) 判据的一部分** —— 所以失配开关必须在本张就建好，不能等到 12 才现搭。
