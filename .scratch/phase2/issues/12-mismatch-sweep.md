# 12: ±30% 参数失配扫描与参数一致对照组

Status: ready-for-agent
Type: research

**What to build:** 把"这个 MPC（模型预测控制）是否依赖精确模型"从**假设**变成**可测结论**。

**Blocked by:** [08](08-sitl-z0-airframe.md), [09](09-sitl-tier-a-closed-loop.md)

- [ ] 单参数 **±30%** 扫描（质量 / 推力系数 / 转动惯量 / 内环时间常数），每次记录：是否发散、稳态误差、求解耗时变化
- [ ] 跑**参数完全一致**的对照组，给出干净对比（不是只跑失配那一侧）
- [ ] 结论写成"**在什么失配范围内仍稳定、从哪个参数先开始退化**"，而不是"感觉挺鲁棒"
- [ ] 明确标注这些是**仿真结论**，不能直接外推到 z0 实机 —— sim-to-real 的 gap 来源（推力曲线、电池跌落、动捕时延）在本阶段**未被覆盖**
- [ ] 若发现某个参数对稳定性最敏感 → 检查它是否已在 Phase 3 的四项前置测量里；若没有，**在 [10](10-param-measure-backfill.md) 里请求加测**，而不是自己去补一个数
- [ ] 结论回链到 [11](11-sitl-tier-b-seam3.md) 的"错参数也能飞稳"判据，说明它是**被满足**还是**有边界**

---

**为什么本张与 [11](11-sitl-tier-b-seam3.md) 分开**：11 把失配对象当**判据的一部分**（必须过线）；本张把它当**被研究的变量**（要画出边界）。前者是一个通过/不通过的结论，后者是一张随参数变化的图 —— 混在一张里会让"11 过了"掩盖掉"其实只有 ±10% 才稳"。
