1. 读数 ≈ **0.37 A**，而**不是 0**。工具的提示语写「未解锁时它应≈0」——

   作为**未解锁、仅机载电子设备工作**的静态电流量级合理（对照 `BAT_AVRG_CURRENT = 15.0`）。
   但**要更硬的话应当再采一组**（换一次上电、或对照 `BAT1_CAPACITY` 的积分）。
2. ☠️ **原写「本条不推翻 A4 的机制描述 —— 缺陷在上游仍成立，本机读数只说明本机没被它击中；不要据此认为上游文档写错了」—— 已作废**（推翻处见 §A4 / `params-analysis.md` §3.5.1）。**

### H.6 D3（程序解锁）：合法性、前置、与 ch5 的关系

### H.12 ★ 开始键的**现场动作要点：每次压住 ≥ 0.3 s**（2026-09-23，台架实测）

`debounce_ms = 200` 对上 `/mavros/rc/in` 实测的 **10 Hz**（帧间隔 100 ms）⟹
**连续 3 帧**才够一次确认，而第 3 帧必须落在 `t0 + 200 ms` 之后。夹具发 rc 用的是**真 10 Hz
rclpy 定时器**，抖动是真实的：`test_control_track.py` 的 T1/T6 里，第二次按键曾经
