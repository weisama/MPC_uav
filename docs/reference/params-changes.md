## G. 一页速查：**只做三件事**的话

1. **导出 z0 自己的参数，与本表 diff** —— 因为 `z0.params` 是别的机器导出的（F2）。
2. **改 `NAV_RCL_ACT = 1`（Hold）**，并**上电核实电池电流是否中招**（A1 / A4）。
3. **量电机位置 + 量 `EKF2_EV_POS_*` 外参 + 实测悬停油门**（A2 / C2 / C1）——
   然后**判断几何是否只是均匀缩放**（若是，A3 不用重调）。
