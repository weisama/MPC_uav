# 第 0 章 摘要

z0 是一台涵道四旋翼，机架为 OddityRC XI35 Pro；飞控是 MicoAir NxtPX4v2，运行 PX4 的 MicoAir 厂商构建；机载计算机是 Jetson Orin NX，室内定位由 Nokov 动捕经 VRPN 提供。项目的目标不是再造一台能飞的机器，而是把 z0 建成一个可复用的自主飞行平台，并让模型预测控制（MPC）接管飞控内置 PID。

四阶段路线遵循「每个阶段只引入一个新变量」。Phase 1 在真机上打通「动捕 → 机载计算机 → offboard → 飞控 → 飞机」的位置链路，控制仍是 PX4 内置 PID；Phase 2 把 (C) 级模型预测控制接进控制回路，但只在 SITL 中闭环；Phase 3 整理入口层、`docs/` 与未结票，不引入新变量；Phase 4 让模型预测控制在真机上完成悬停、正方形与 8 字三条轨迹的自由飞，阶梯 2 未达标后由操作者裁定跳过。本报告（Phase 5）把散落在话题包、SITL 证据与文档里的结论收成一条可重跑的数据管线，并在同一时间零点与同一轨迹原点下比较目标、offboard、模型预测控制仿真与模型预测控制实飞四个源。
